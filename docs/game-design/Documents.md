# FUTUREMODE 遊戲文檔

## 目標
本文檔描述本次 Hackathon 實際要交付與演示的可玩版本，而非不受時程限制的完整商業版規格。
該公司的目標是透過這個 Hackathon 找到能夠被放在自家產品中的小遊戲。主要演示對象是 Hackathon 評審，同時以第一次接觸遊戲、只有一至三分鐘空檔的 NOXCAT 手機用戶作為目標玩家。
NOXCAT 做電子錢包與區塊鏈，因此遊戲的資產資料結構和擁有權流轉紀錄需與未來上鏈相容。本次 DEMO 僅模擬資產與擁有權的流轉，不宣稱已完成真實的鏈上交易。
> Feel Nothing. Do Everything.
NOXCAT 口號

## 要求
有以下硬性要求：
- NOXCAT 本身需要是主角
- 十秒鐘內能夠簡單易懂的開啟遊戲
- 支援手機 + 單指操作
- 一局結束以後會願意再開一局
- 評審演示需盡力在兩分鐘內完成一次「戰鬥死亡 → 資產掉落 → 另一名玩家取得 → 原主人查看去向」的核心循環

## Hackathon MVP 範圍
本次 MVP 的最小完整流程為：

1. 玩家 A 在十秒內開始戰鬥。
2. 玩家 A 的可掉落 NOXCAT 在戰鬥中死亡。
3. 結算畫面顯示資產已離開玩家 A，並進入該關卡的共享戰利品池。
4. 玩家 B 挑戰並通關同一關卡，從共享戰利品池中獲得該 NOXCAT。
5. 玩家 A 可在走失列表查看該 NOXCAT 的關卡位置，或取得者的玩家 ID。

正式玩法中，玩家通關時是從關卡的共享戰利品池中隨機取得獎勵。為了讓兩分鐘評審演示可重現，DEMO 使用預先準備的玩家與掉落資料，並固定演示結果。

完整交易所、PVP 與真實鏈上交易不是這條 MVP 核心流程的必要條件，實作優先度低於戰鬥、死亡掉落、共享戰利品池、取得與走失追蹤。

## 遊戲核心
集換式 NOXCAT 彈珠遊戲。遊戲中的每隻角色都是具有不同外觀、數值與身分的 NOXCAT 變體，不另外使用與 NOXCAT 無關的寵物作為主角。

玩家會透過挑戰地下城獲得新的 NOXCAT、武器、道具與特效。本作最不可取代的核心承諾是：
> 你失去的 NOXCAT，會成為另一位玩家冒險中的戰利品。

若可掉落的 NOXCAT 在戰鬥中 HP 歸零，不論該局最後勝敗，都會立即失去並留在該地下城關卡的共享戰利品池中，成為其他玩家通關時可能取得的獎勵。這項轉移不會因玩家最後獲勝而撤銷。

### 初始 NOXCAT 與掉落保護

- 每位玩家初始擁有三隻最普通的 NOXCAT。
- 這三隻初始 NOXCAT 受系統保護，在戰鬥中 HP 歸零時不會失去，也不會進入共享戰利品池。
- 玩家後續取得的可收藏 NOXCAT 不受此保護，除非有其他明確的保護道具或規則。
- 初始角色的保護狀態需在編隊與角色詳情中清楚標示，避免玩家誤解掉落風險。

### 共享戰利品池

- 每個地下城關卡擁有自己的共享戰利品池。
- 可掉落 NOXCAT 死亡後，角色與其攜帶的可掉落道具會被記錄在該關卡中。
- 其他玩家通關該關卡時，有機會從共享戰利品池中隨機獲得其中的 NOXCAT 或道具。
- 每件掉落資產只能被一位玩家取得一次；取得後必須從共享戰利品池移除，不可複製或重複領取。

## 遊戲細項規則
以下畫面是產品規格的完整脈絡。本次 Hackathon MVP 優先確保主畫面／開局、戰鬥、結算、共享戰利品與走失追蹤流程可完整演示；其他畫面可依時程簡化。
遊戲需要幾個重要畫面：
1. 主畫面，也是進入戰鬥的畫面。目的是要快速開局。
2. 寵物列表。顯示目前所持有的所有寵物，所持道具。可以調整出戰對伍編組。提供觀賞模式，獨一無二的對話與數值詳細度。
3. 戰鬥畫面。以怪物彈珠式戰鬥的地點。
4. 交易所。可以交易物品。
5. 結算介面。在戰鬥畫面結束時出現，顯示勝利或失敗、獲得與失去哪些寵物或物品。

### 交易介面
上方有兩個tab可選：
1. 交易所
指定玩家，向他發起一項以物易物的請求。
按下左下角加號發起新請求，輸入對方玩家 ID 、交易雙方提供物品則可以送出請求。對方如果通過交易自動完成。請求宣告支付的物品會暫時鎖定，直到交易成功或取消。
![alt text](trade_example.jpg)

已經發起的交易會顯示Pending(無改變)、Accepted(對方的頭像上有綠色勾勾)、Rejected(對方的頭像上有紅色叉叉)。
2. 走失列表
該列表顯示所有因 HP 歸零而掉落的 NOXCAT 和武器狀態，不以整場戰鬥勝敗作為判定條件。若尚未被取得，顯示目前所在關卡；若已被取得，顯示取得者的玩家 ID，供原主人後續發起交易請求。
![alt text](mourn_example.jpg)
僅能看到掉落在哪個關卡或撿走者的 ID。

### 戰鬥介面
參見已經 vibe 出來的東西。
![alt text](combate_example.jpg)
類似怪物彈珠的戰鬥模式。回合順序不由速度屬性決定：玩家方三隻 NOXCAT 依隊伍順序各行動一次，接著由敵方三隻依序各行動一次，之後重複此循環。

每次一隻 NOXCAT 行動時，玩家點擊並拖曳以決定彈射方向，放開手指即發射。NOXCAT 的速度屬性決定彈出時的初始速度大小，不影響行動順序。彈射後可撞擊隊友與敵人，撞擊到敵人時會對其造成傷害。當場上的移動結束後，進入下一隻 NOXCAT 的行動。

### 結算介面
模糊化戰鬥介面以後顯示，大大的顯示戰鬥結果，並在下方綠色或紅色的六邊形中顯示獲得與失去什麼東西。
![alt text](settlement_screen_example.jpg)
若非初始保護的 NOXCAT 在戰鬥中 HP 歸零，玩家會立即失去該 NOXCAT 以及其攜帶的可掉落道具（除非受回家代幣等規則保護）。這項結果不會因整場戰鬥最後獲勝而撤銷。結算畫面需清楚列出哪些資產已失去、哪些資產受保護，以及新獲得的獎勵。

失去的 NOXCAT 與道具會被記錄在該關卡的共享戰利品池中，其他玩家挑戰並通關此關卡時，有機會從獎勵中隨機得到該 NOXCAT 或道具。玩家勝利獲得的資產也可能是其他玩家曾經掉落的資產。

## 模擬所有權與上鏈適配
本次 DEMO 不連接真實區塊鏈，也不執行真實 NFT 或代幣交易。遊戲中顯示的擁有權改變是為了驗證玩法與 NOXCAT 錢包／區塊鏈產品的相符程度。

為保留未來上鏈的可適配性，每筆模擬資產至少需能表達：

- 資產的唯一 ID
- NOXCAT 的外觀、基礎數值與攜帶道具
- 目前擁有者或所在關卡戰利品池
- 資產狀態（受保護、持有中、已掉落或已被取得）
- 狀態改變原因與時間

上述資料結構只代表上鏈適配方向，不代表本次 DEMO 已實作智能合約或分散式儲存。
